# 🎨 Random Box Generator / Генератор случайных блоков

[🇷🇺 Русская версия](#русская-версия) | [🇬🇧 English version](#english-version)

---

## 🇷🇺 Русская версия

Интерактивный скрипт на чистом JavaScript, который автоматически генерирует уникальные цветные блоки на экране через заданные интервалы времени.

### ✨ Особенности проекта
- **📦 Динамическое создание элементов:** Создает главный холст и дочерние элементы (`div`) прямо из JavaScript.
- **🎯 Уникальность позиций и цветов:** Использует цикл проверки, чтобы новые блоки не получали полностью идентичные параметры.
- **⏹️ Автоматическая остановка:** Генерация прекращается, когда достигается лимит ячеек (`cell = 10`).

### 🚀 Как запустить
1. Клонируйте репозиторий или скачайте файлы проекта (`index.html` и `script.js`).
2. Убедитесь, что файлы находятся в одной папке.
3. Откройте файл `index.html` в любом современном браузере.
4. Откройте консоль разработчика (`F12`), чтобы видеть логи создания элементов.

### 🛠️ Используемые технологии
- HTML5
- CSS3 (Absolute Positioning)
- JavaScript (DOM API, Timers, Math random)

## 🇬🇧 English version

An interactive vanilla JavaScript script that automatically generates unique colored boxes on the screen at specified time intervals.

### ✨ Features
- **📦 Dynamic Element Creation:** Creates the main container and child elements (`div`) directly from JavaScript.
- **🎯 Unique Positions & Colors:** Uses a validation loop to ensure new boxes don't get completely identical parameters.
- **⏹️ Automatic Stop:** Generation automatically stops when the cell limit is reached (`cell = 10`).

### 🚀 How to Run
1. Clone the repository or download the project files (`index.html` and `script.js`).
2. Make sure the files are located in the same folder.
3. Open the `index.html` file in any modern web browser.
4. Open the Developer Console (`F12`) to view the generation logs.

### 🛠️ Technologies Used
- HTML5
- CSS3 (Absolute Positioning)
- JavaScript (DOM API, Timers, Math random)
