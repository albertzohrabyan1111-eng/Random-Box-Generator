# 🎨 Random Box Generator / Генератор случайных блоков

## 🇷🇺 Русская версия

Интерактивный скрипт на чистом JavaScript, который автоматически генерирует уникальные цветные блоки на экране через заданные интервалы времени.

### ✨ Особенности проекта
- **📦 Динамическое создание элементов:** Создает главный холст и дочерние элементы (`div`) прямо из JavaScript.
- **🎯 Уникальность позиций и цветов:** Использует цикл проверки, чтобы новые блоки не получали полностью идентичные параметры.
- **⏹️ Автоматическая остановка:** Генерация прекращается, когда достигается лимит ячеек (`cell = 10`).

### 📂 Как создать проект с нуля (Инструкция)

Так как у вас в папке изначально был только файл со скриптом, выполните эти простые шаги, чтобы всё заработало:

1. **Создайте файл `index.html`:**
   В той же папке, где лежит ваш файл со скриптом, создайте новый текстовый файл и назовите его `index.html` (убедитесь, что расширение не `.txt`).

2. **Добавьте базовую разметку:**
   Откройте созданный `index.html` в любом текстовом редакторе (например, VS Code, Блокнот или Notepad++) и вставьте туда этот код:

   ```html
   <!DOCTYPE html>
   <html lang="ru">
   <head>
       <meta charset="UTF-8">
       <meta name="viewport" content="width=device-width, initial-scale=1.0">
       <title>Random Box Generator</title>
   </head>
   <body>
       
       <!-- Подключаем ваш файл со скриптом (укажите правильное имя файла, если оно отличается, например script.js) -->
       <script src="script.js"></script>
   </body>
   </html>
