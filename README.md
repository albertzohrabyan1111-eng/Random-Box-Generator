# Random Box Generator

Интерактивный скрипт на чистом JavaScript, который автоматически генерирует уникальные цветные блоки на экране через заданные интервалы времени.

## Особенности проекта
- **Динамическое создание элементов:** Создает главный холст и дочерние элементы (`div`) прямо из JavaScript.
- **Уникальность позиций и цветов:** Использует цикл проверки, чтобы новые блоки не накладывались друг на друга с абсолютно одинаковыми параметрами.
- **Автоматическая остановка:** Генерация прекращается, когда достигается лимит ячеек (`cell = 10`).

## Как запустить
1. Клонируйте репозиторий или скачайте файлы проекта (`index.html` и `script.js`).
2. Убедитесь, что файлы находятся в одной папке.
3. Откройте файл `index.html` в любом современном браузере.
4. Откройте консоль разработчика (`F12`), чтобы видеть логи создания элементов.

## Используемые технологии
- HTML5
- CSS3 (Absolute Positioning, Flex/Grid принципы)
- JavaScript (DOM API, Timers, Math random)
